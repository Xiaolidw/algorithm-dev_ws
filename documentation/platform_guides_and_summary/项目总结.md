# YZBot 移动操作机器人仿真项目说明

## 1. 项目概述

YZBot 是一个基于 ROS 2 Humble 的移动操作机器人仿真项目，面向移动机器人导航、机械臂运动规划、仿真抓取以及本地大语言模型交互等场景。

项目在 Gazebo Classic 中搭建了由差速移动底盘、六轴机械臂、夹爪、二维激光雷达、RGB 相机和 RGB-D 相机组成的机器人模型，并集成以下功能：

- 使用 Gazebo 进行机器人和场景物理仿真；
- 使用 ros2_control 控制机械臂和夹爪；
- 使用 MoveIt 2 完成机械臂运动规划和轨迹执行；
- 使用 Nav2 完成地图定位和移动底盘导航；
- 使用 Cartographer 或 RTAB-Map 进行建图实验；
- 使用 Gazebo LinkAttacher 服务模拟物体抓取和释放；
- 使用 llama.cpp 运行本地 Qwen 模型，并通过 ROS 2 话题发布模型回复。

项目当前已经完成各基础模块的搭建，适合作为移动操作机器人、仿真抓取及“大模型 + ROS 2”实验平台。自主导航、目标识别、机械臂抓取和放置之间的全自动任务编排仍需继续完善。

## 2. 运行环境

推荐环境如下：

| 项目 | 版本或说明 |
| --- | --- |
| 操作系统 | Ubuntu 22.04 |
| ROS | ROS 2 Humble |
| 仿真平台 | Gazebo Classic 11 |
| 机械臂规划 | MoveIt 2 |
| 移动导航 | Nav2 |
| 控制框架 | ros2_control |
| 本地大模型 | Qwen2.5-Coder 0.5B GGUF |
| 推理框架 | llama.cpp |

主要 ROS 依赖包括：

```bash
sudo apt install ros-humble-desktop-full
sudo apt install gazebo ros-humble-gazebo-*
sudo apt install ros-humble-moveit ros-humble-moveit-setup-assistant
sudo apt install ros-humble-controller-manager
sudo apt install ros-humble-joint-trajectory-controller
sudo apt install ros-humble-joint-state-broadcaster
sudo apt install ros-humble-nav2-bringup ros-humble-nav2-*
```

如果需要运行 Cartographer 或 RTAB-Map，还需要安装对应的 ROS 2 功能包。

## 3. 项目组成

项目源码位于：

```text
~/dev_ws/src/yzbot
```

主要目录如下：

```text
yzbot/
├── mybot_description/       # 机器人 URDF/Xacro、传感器模型和 Gazebo 世界
├── mybot/                   # MoveIt、ros2_control 配置及启动文件
├── bot_navigation/          # Nav2、Cartographer、地图和 RViz 配置
├── IFRA_LinkAttacher/       # Gazebo 抓取/释放插件及服务接口
├── tools_demo/              # llama.cpp 对话及 ROS 2 话题发布程序
├── cube_control.sh          # 方块吸附/释放辅助脚本
├── my_send_goal.sh          # 机械臂关节轨迹示例
├── pick_on.sh               # 夹爪动作示例
├── pick_off.sh              # 夹爪动作示例
└── send_goal_pick.sh        # 机械臂和夹爪组合轨迹示例
```

### 3.1 mybot_description

该功能包负责机器人和仿真环境的描述，主要包含：

- 差速移动底盘；
- 六轴机械臂；
- 单自由度夹爪；
- 二维激光雷达；
- RGB 相机；
- 安装在机械臂末端的 RGB-D 相机；
- `room.world`、`cloister.world` 和 `box.world` 等 Gazebo 场景。

组合机器人模型入口为：

```text
mybot_description/urdf/originbot_with_rgbd_gazebo_arm.xacro
```

### 3.2 mybot

该功能包负责机械臂运动规划和控制，主要包含：

- MoveIt SRDF；
- KDL 运动学求解器配置；
- 机械臂和夹爪控制器配置；
- 关节限制和初始位置；
- Gazebo、MoveGroup 和 RViz 启动文件。

机械臂使用以下控制器：

- `arm_controller`：控制 `joint1` 至 `joint6`；
- `gripper_controller`：控制 `finger_joint1`；
- `joint_state_broadcaster`：发布 `/joint_states`。

### 3.3 bot_navigation

该功能包负责移动底盘的定位、建图和导航，主要包含：

- Nav2 参数；
- AMCL 定位参数；
- Cartographer 配置；
- RTAB-Map 启动文件；
- 栅格地图；
- 导航和建图 RViz 配置。

导航使用的核心数据为：

```text
/scan       激光雷达数据
/odom       底盘里程计
/cmd_vel    底盘速度指令
/tf         坐标变换
/map        栅格地图
```

### 3.4 IFRA_LinkAttacher

该模块是第三方 Gazebo 插件，通过在两个 Gazebo link 之间创建临时固定关节来模拟抓取。

提供以下服务：

```text
/ATTACHLINK    吸附物体
/DETACHLINK    释放物体
```

默认的 `room.world` 已加载该插件，因此可以对场景中的红色和蓝色方块进行吸附或释放。

### 3.5 tools_demo

该功能包用于连接本地 llama.cpp 服务，包含：

- 普通终端对话程序 `chat_interactive.py`；
- ROS 2 对话程序 `chat_interactive_ros.py`；
- `chat` 和 `chat_ros` 两个 ROS 2 可执行入口。

`chat_ros` 会将大模型回复作为 `std_msgs/String` 发布到：

```text
/llama_command
```

当前项目尚未实现 `/llama_command` 的任务执行订阅节点，因此该话题目前主要用于演示大模型与 ROS 2 的通信。

## 4. 系统工作流程

完整系统的数据流如下：

```text
Gazebo
├── robot_state_publisher ───────────────→ /tf、/tf_static
├── gazebo_ros_diff_drive ← /cmd_vel ───→ /odom
├── Gazebo 激光雷达 ─────────────────────→ /scan
├── Gazebo 相机 ─────────────────────────→ 图像/深度话题
├── gazebo_ros2_control
│   ├── arm_controller
│   ├── gripper_controller
│   └── joint_state_broadcaster ─────────→ /joint_states
└── LinkAttacher ────────────────────────→ 抓取/释放服务

Nav2
├── 输入：/map、/scan、/odom、TF
└── 输出：/cmd_vel

MoveIt 2
├── 输入：机器人模型、/joint_states、TF
└── 输出：机械臂和夹爪轨迹 Action

llama.cpp
└── tools_demo ──────────────────────────→ /llama_command
```

## 5. 编译工作区

首次使用或修改配置后，在工作区根目录执行：

```bash
cd ~/dev_ws
colcon build --symlink-install
source install/setup.bash
```

每个新终端都需要执行：

```bash
source /opt/ros/humble/setup.bash
source ~/dev_ws/install/setup.bash
```

## 6. 启动完整仿真系统

完整系统建议在多个终端中依次启动。

### 6.1 启动 Gazebo 组合机器人

```bash
ros2 launch mybot gazebo_world.launch.py
```

该命令启动：

- Gazebo `room.world`；
- 移动底盘；
- 六轴机械臂和夹爪；
- 激光雷达、RGB 相机和 RGB-D 相机；
- robot_state_publisher；
- ros2_control 控制器；
- LinkAttacher 抓取插件。

### 6.2 启动 MoveIt 2

```bash
ros2 launch mybot my_moveit_rviz.launch.py
```

该命令启动：

- MoveGroup；
- MoveIt RViz 插件；
- 机械臂运动规划；
- 机械臂和夹爪轨迹执行接口。

### 6.3 启动 Nav2

```bash
ros2 launch bot_navigation nav_bringup_gazebo.launch.py
```

启动后需要在 RViz 中使用 `2D Pose Estimate` 设置机器人初始位姿。AMCL 获得初始位姿后才会建立：

```text
map → odom
```

之后可使用 RViz 的 `Nav2 Goal` 或 `2D Goal Pose` 下发导航目标。

## 7. 本地大模型使用方法

### 7.1 测试模型

```bash
llama-cli \
  -m qwen2.5-coder-0.5b-instruct-q4_k_m.gguf \
  -n 512 \
  -c 2048 \
  -sys "你是编程小助手" \
  -co \
  -cnv \
  --threads 8
```

### 7.2 启动 llama.cpp 服务

```bash
llama-server \
  -m ~/llama.cpp/qwen2.5-coder-0.5b-instruct-q4_k_m.gguf \
  -c 2048 \
  --threads 8 \
  --port 8081
```

默认对话服务地址为：

```text
http://localhost:8081/v1/chat/completions
```

### 7.3 普通终端对话

```bash
cd ~/dev_ws/src/yzbot/tools_demo/tools_demo
python3 chat_interactive.py
```

也可以在完成工作区编译后执行：

```bash
ros2 run tools_demo chat
```

### 7.4 ROS 2 对话

```bash
ros2 run tools_demo chat_ros
```

选择发布回复后，可使用以下命令查看消息：

```bash
ros2 topic echo /llama_command
```

## 8. 抓取和控制接口

### 8.1 机械臂轨迹 Action

```text
/arm_controller/follow_joint_trajectory
```

### 8.2 夹爪轨迹 Action

```text
/gripper_controller/follow_joint_trajectory
```

### 8.3 手动吸附方块

项目提供了辅助脚本：

```bash
cd ~/dev_ws/src/yzbot
./cube_control.sh on red 1
```

释放方块：

```bash
./cube_control.sh off red 1
```

脚本支持：

```text
颜色：red、blue
编号：1～5
操作：on、off
```

也可以直接调用服务：

```bash
ros2 service call /ATTACHLINK linkattacher_msgs/srv/AttachLink \
"{model1_name: 'six_arm', link1_name: 'link6', model2_name: 'red_cube_1', link2_name: 'link'}"
```

## 10. 后续扩展方向

该项目可以进一步扩展为完整的“大模型驱动移动操作机器人”系统。建议采用以下分层结构：

```text
自然语言输入
    ↓
大模型生成结构化任务
    ↓
任务校验与状态机
    ├── Nav2 移动到抓取位置
    ├── 感知模块确认目标
    ├── MoveIt 执行抓取
    ├── LinkAttacher 模拟持物
    ├── Nav2 移动到目标区域
    └── MoveIt 放置并 Detach
```

大模型适合负责高层任务理解和步骤规划，具体机器人动作应由经过范围校验、状态检查和失败恢复的确定性 ROS 2 节点执行。

## 11. 总结

YZBot 已经集成移动底盘、机械臂、夹爪、传感器、Gazebo、MoveIt 2、Nav2、仿真抓取插件和本地大语言模型，具备移动操作机器人实验平台的基本形态。

当前项目的核心价值是将多个 ROS 2 子系统集中在同一个仿真环境中，为后续研究以下内容提供基础：

- 移动机器人定位与导航；
- 机械臂运动规划与控制；
- 移动操作机器人协同；
- 仿真抓取与放置；
- 本地大模型与 ROS 2 通信；
- 自然语言驱动的机器人任务规划。

在进一步统一模型与控制参数、完成自动抓取状态机并接通大模型任务接口后，该项目可以发展为一套完整的智能移动抓取仿真系统。
