# Windows competition-material import

This import organizes competition-related Windows files by their practical role:

- `competition_runtime/` — desktop exports, startup scripts, maps, world files, and working ROS configuration.
- `visualization/` — coStudio layouts, packages, and dashboard source code.
- `codex_work/` — Codex patch sets, remote source snapshots, and handoff notes.
- `references/` — ROS reference workspaces and historical national-competition source snapshots.
- `documentation/` — competition rules, platform instructions, project summaries, and supporting media.

The source sets were copied without build output, installed artifacts, runtime logs, Python caches, nested Git metadata, or JavaScript dependencies. Large unversionable assets (including the 1.8 GB `参考资料.zip`, videos over GitHub's 100 MB file limit, and installer executables) remain on the Windows desktop and are not part of this Git repository.
