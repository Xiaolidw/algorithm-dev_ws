                基于改进 A*-DWA 融合算法的移动机器人路径规划研究
                                                                                      郭伟龙,孙 渊*
                                                                        (上海电机学院 机械学院，上海 201306 )


                        摘 要：针对移动机器人导航过程中单一路径规划算法难以兼顾全局路径质量与局部避障实
                        时性的问题，本研究提出一种改进 A*与动态窗口法(Dynamic Window Approach,DWA)相结合
                        的移动机器人路径规划算法。首先，根据节点邻域障碍物密度自适应调整启发函数权重，并
                        结合转向惩罚优化全局路径；其次，在 DWA 评价函数中引入方位角动态权重，提高目标收
                        敛和局部避障能力；最后，提取改进 A*算法生成的全局路径关键节点，并将其作为 DWA 算
                        法的阶段性局部目标点，实现全局路径规划与局部实时避障的有效融合。仿真结果表明，改
                        进的融合算法所提算法在路径长度、转折次数和运行时间等指标上均有所改善。实验验证了
                        所提算法在静态未知障碍物和动态障碍物环境下的有效性。
                        关键词：路径规划；改进 A*算法；融合算法；动态避障

                                Research on mobile robot path planning based on an improved
                                                                         A*-DWA fusion algorithm
                                                                                 GUO Wei-long, SUN Yuan*

                                          (Mechanical College, Shanghai Dianji University, Shanghai 201306, China)

                        Abstract: To address the problem that a single path planning algorithm for mobile robot navigation
                        often fails to balance global path quality and real-time local obstacle avoidance, this paper proposes
                        a mobile robot path planning algorithm that integrates an improved A* algorithm with the Dynamic
                        Window Approach (DWA). First, the heuristic function weight is adaptively adjusted according to
                        the obstacle density in the neighborhood of each node, and a steering penalty is introduced to
                        optimize the global path. Second, a dynamic azimuth-angle weight is incorporated into the
                        evaluation function of DWA to enhance target convergence and local obstacle avoidance capability.
                        Finally, key nodes are extracted from the global path generated by the improved A* algorithm and
                        used as staged local target points for DWA, thereby achieving effective integration of global path
                        planning and real-time local obstacle avoidance. Simulation results show that the proposed
                        improved fusion algorithm achieves better performance in terms of path length, number of turns,
                        and running time. Experimental results further verify the effectiveness of the proposed algorithm in
                        environments with unknown static obstacles and dynamic obstacles.
                        Keywords: path planning; improved A* algorithm; fusion algorithm; dynamic obstacle avoidance
