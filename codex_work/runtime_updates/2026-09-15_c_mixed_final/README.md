# 2026-09-15 C 区混合终验

本目录固化 C 区动态门禁、上半区轨道绕行和 A 区红色双排放置的最终代码与验证证据。

## 已验证结果

- `regression_three_red_A_staggered_red3rail_20260915.log`：连续 3 个红块到 A，3/3，通过时间 213.986 s，恢复 0。
- `final_mixed_2blueC_3redA_20260915.log`：2 个蓝块到 C、3 个红块到 A，5/5，通过时间 444.423 s，恢复 0。
- C 两块最终中心距 0.327 m；A 三块最终最小中心距 0.172 m。全部通过水平、静止、区域、落地高度和历史库存联合验收。

## 本轮保留的最小修复

- C 北侧交叉门禁：仅当动态障碍物向南远离且 `y<=-4.50` 时提前放行；向北接近时保持等待。
- 红色 A 使用双排错列槽位；蓝色 A 保持内收单排，避免两种不同机械臂扫动共用错误槽位几何。
- red3 与 red4/red5 一样使用上半区移动障碍轨道的固定西侧绕行，包括空载夹取和携带退出。
- 空 A 区先使用边缘候选，继续保留槽位认领、底盘代价、三维落地和库存间距门禁。

## 性能结论

A 单件约 65～78 s；C 单件约 115～122 s。C 的主要耗时来自每件进出通道的动态障碍安全等待，不是 Nav2 恢复。后续提速应单独验证基于到达时间的安全时间窗，禁止通过移动地图、缩小墙石安全距离或取消方向门禁来实现。
