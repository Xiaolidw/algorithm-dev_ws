## C 区外部方案检索与下一阶段设计（2026-10-01）

检索 Nav2、Open-RMF 及相近仓储导航项目后，外部成熟做法与本项目日志结论一致：固定仓储走廊适合图式/多点连续路线；动态障碍应在路线层预测或触发重路由，同时保留下层独立碰撞监控；末端操作使用“远端导航到 staging + 近端专用控制”的分层结构。参考：Nav2 `NavigateThroughPoses` 与 Simple Commander、Route Server、RPP、Collision Monitor、Docking Server，以及 Open-RMF 对只读动态车辆轨迹预测的示例。

### 建议路线图

1. **新增墙顶上方短通道，而不是继续只走 y=-6.90。** 保留南路作为回退，新增候选 `U-west=(-0.50,-3.00)`、`U-east=(4.10,-3.00)`。Wall_118 顶端约 y=-3.533，U 通道从其上方通过；动态障碍 2 仅在 `y<=-4.50 and vy<0` 时放行，跨线中心距至少 1.50 m。入 C 为 `common→U-west→[门禁]→U-east→C funnel`；出 C 反向。先逐点做 footprint cost 探测，再做单件、双件、三件回归。几何上每次入/出比南路约少 3.3 m，三入两出理论减少约 16.5 m，保守目标节省 12–22 s/三件。
2. **把 waypoint 串改为一次连续动作。** 当前每个 waypoint 都执行 `NavigateToPose→取消→停车→重建路径`。门禁两侧仍保留明确停车点，但门禁放行后的 `U-east→funnel→pre-approach` 用 `NavigateThroughPoses` 或 `ComputePathThroughPoses + FollowPath` 一次执行；退出放行后的 `U-west→下一拾取走廊` 同理。预期减少 5–8 次 cancel/settle/reacquire，目标节省 10–18 s/三件。
3. **退出时提前选择下一物块并直达，不再统一回 common。** 批次任务已知且物块最多 5 个，可在当前件放置库存验收后，为下一件运行一次只读候选选择并锁定 ID。通过轨道后，红3/红4直接接 `(-2.75,2.00)→(-2.75,3.50)`；普通红/蓝直接接对应 pickup dock；若实时成本变 lethal 再回退 `(-0.50,-1.00)`。这能合并“C exit 最后一段”和“下一件 pickup 第一段”，目标节省 4–7 s/非末件，即 8–14 s/三件。
4. **建立 C 槽位直线漏斗，消除第一次约 5 s 原地对向。** 对每个动态槽位生成 `funnel=(dock_x,dock_y+1.00,yaw=-pi/2)` 和现有 `pre=(dock_x,dock_y+0.45,yaw=-pi/2)`；连续路径从东侧先到 funnel，再沿 x 不变向南进入 pre。只有实际 yaw 误差仍大于 0.12 rad 才调用第一次 `align_dropoff_heading`，否则直接低速入位。通过后再单变量把 0.16 m/s 末端上限试至 0.20/0.22 m/s，并在距离 0.22 m 内恢复低速。目标节省 4–6 s/件，约 12–18 s/三件。
5. **任务顺序使用“路程 + 障碍相位 + 槽位”联合代价。** 对三件仅有 6 种顺序，可穷举；状态包含当前节点、障碍 y/vy、剩余物块和保留槽位。每完成一个 checkpoint 用实时相位重算。三蓝第三件曾静止等待 10.85 s，允许选择稍远但能命中窗口的物块，目标减少 5–12 s 的随机相位等待。Open-RMF 的只读车辆示例同样把预测轨迹提交给时间调度层，而不是只依赖瞬时占据栅格。

### 避障原则

- 不关闭 Collision Monitor，不缩小 footprint，不删除 0.40 s 稳定确认。继续让 `/scan_costmap` 服务全局/局部规划，让原始 `/scan` 进入独立 Collision Monitor；这符合 Nav2 将 Collision Monitor 放在导航栈下方作为急停安全层的设计。
- 不建议仅降低 inflation radius。RPP 的速度约束直接使用 inflation cost 推断障碍距离，盲目改变 inflation 会同时改变速度估计与安全边界。先通过路线远离高成本区、连续路径和 staging 漏斗减少减速。
- Route Server 的 CollisionMonitor/ReroutingService 可作为长期重构；本场只有少量固定走廊，第一版直接用 6–8 个有向节点和现有相位模型更快落地。

### 预期与验证顺序

收益存在重叠，不能简单相加。按“U 通道→连续多点→提前选下一物块→C 漏斗→相位联合排序”逐项回归，保守目标为三红从 267.800 s 降至 **225–240 s**，三蓝从 247.332 s 降至 **205–225 s**。每项必须依次通过单件几何/碰撞证据、双件退出再进入、三红和三蓝各 3/3、恢复 0；失败即回退单变量，不同时修改安全门禁和速度。
